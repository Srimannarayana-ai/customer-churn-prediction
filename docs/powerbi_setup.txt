Data source

03_outputs/PowerBI/Churn_Scorecard_Data.xlsx

Refresh after rebuilding data
-----------------------------
1. python scripts/build_churn_scorecard.py
2. Keep Churn_Scorecard_Data.xlsx in 03_outputs/PowerBI/
3. Open the .pbix in Power BI Desktop
4. Home → Refresh
5. File → Save
